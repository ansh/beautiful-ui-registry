Unofficial shadcn registry

Beautiful UI, installable.

Beautiful UI publishes AI-native interface primitives as MIT copy-paste components, but ships no registry — so there's no way to install one from a terminal. This adds that layer. 

npx shadcn@latest add https://beautiful-ui.chorus.host/r/thinking-state.json

Items

Every component pulls theme as a registry dependency, so installing one brings the token layer with it. Requires Tailwind v4.

Provenance

The token layer is transcribed exactly from the stylesheet published at beautifului.dev. The components are reconstructions — the site ships no repository and no source maps, so they were rebuilt from the server-rendered markup and the class strings in the client bundle. Layout, class names and easing curves match; the behaviour behind them was rewritten. Ten of the twenty primitives are covered.

Built for Shane to take over. Drop the real sources into registry/beautiful-ui/ui/, rebuild, and serve /r/ from beautifului.dev — then this host can go away.
